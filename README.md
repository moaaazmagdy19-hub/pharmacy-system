# نظام إدارة الصيدلية المتكامل (فارما بلس | PharmacyOS)

نظام إدارة صيدلية متكامل، مصمم خصيصاً لتلبية متطلبات الصيدليات والتعامل مع حسابات العملاء، البيع الآجل والمديونيات، صرف الروشتات، تتبع الأطباء والمخزون، ودفتر الأستاذ المالي غير القابل للحذف.

---

## 🌟 أبرز مميزات النظام

1. **واجهة طبية عربية متكاملة (RTL)**:
   - تصميم طبي معتمد بالألوان المعتمدة (الأبيض، درجات الأزرق الملكي، الكحلي، والرمادي الناعم).
   - خطوط عربية واضحة (Cairo) مريحة للقراءة والاستخدام اليومي السريع للصيادلة.

2. **نقطة البيع السريعة (POS)**:
   - بحث فوري عن الأدوية بالاسم التجاري، المادة الفعالة، أو بقارئ الباركود.
   - اختيار العميل مع عرض فوري لمديونياته السابقة إن وجدت.
   - **العميل المتكرر**: إمكانية استعراض كافة الأدوية التي صرفها العميل سابقاً وجرعاتها وإعادة صرفها بنقرة واحدة.
   - حساب فوري وتلقائي لتراكم المديونية: `الرصيد السابق + المتبقي من الفاتورة = إجمالي المديونية الجديدة`.
   - إصدار وطباعة إيصال بيع حراري (80mm Thermal Receipt) وإيصال فواتير كامل.

3. **الملف الشامل للعميل (Customer Profile)**:
   - الرصيد الحالي المستحق، إجمالي المشتريات، وإجمالي المسدد.
   - **سجل المشتريات**: فواتير العميل مرتبة زمنياً مع تفاصيل الأدوية وطريقة السداد.
   - **سجل الأدوية السابقة**: جدول يوضح كل دواء صرفه العميل، كميته، تاريخ صرفه، والطبيب المعالج، لإجابة فورية عن سؤال: *"أنا أخذت دواء ايه المرة اللي فاتت؟"*.
   - **كشف الحساب الجاري (Running Balance)**: تدرج المديونية سنداً بسند مع الرصيد بعد كل عملية.
   - إمكانية إرسال رسالة تذكير مهذبة بالمديونية عبر واتساب بنقرة واحدة.

4. **إدارة المخزون والتنبيهات**:
   - متابعة الأرصدة والحدود الدنيا وحدود إعادة الطلب.
   - تنبيهات فورية للنواقص والأدوية قريبة انتهاء الصلاحية (&lt; 60 يوماً).
   - تسوية وجرد المخزون مع توثيق سبب التسوية ومسؤول العملية.

5. **الروشتات الطبية والأطباء**:
   - تسجيل روشتات متعددة الأدوية بالجرعات والتعليمات.
   - إمكانية تحويل أي روشتة مباشرة لنقطة البيع وصرفها بنقرة واحدة.
   - دليل الأطباء وإحصائيات المبيعات والروشتات المحولة من كل عيادة.

6. **دفتر الأستاذ المالي (Financial Ledger)**:
   - سجل محاسبي ثابت غير قابل للحذف (Immutable Ledger) لضمان دقة الحسابات.
   - احتساب مديونية كل عميل ديناميكياً من واقع الفواتير وسندات التحصيل.

7. **التقارير وسجل التدقيق**:
   - تقارير تفصيلية: المبيعات، مديونيات العملاء، حركة الأدوية، أداء الأطباء، وإنتاجية الصيادلة.
   - دعم التصدير المباشر لملفات Excel (CSV) والطباعة.
   - سجل أمني كامل (Audit Log) يوثق كل إضافة وتعديل وسداد.

8. **قاعدة بيانات Supabase + تخزين محلي فوري**:
   - كود تهيئة كامل لجداول PostgreSQL وسياسات الأمان RLS موجود في مسار: `supabase/schema.sql`.
   - لوحة إعدادات تتيح ربط حساب Supabase أو تصدير واستيراد نسخ احتياطية JSON.
   - محمل ببيانات تجريبية مصرية واقعية (عملاء، أدوية كـ Panadol و Augmentin و Congestal، أطباء، وروشتات).

## 🚀 تشغيل النظام

التطبيق يعمل حالياً محلياً على منفذ **5180**:
```bash
http://localhost:5180/
```

لتشغيله يدوياً في أي وقت:
```bash
cd "C:\Users\Techno Zone\.gemini\antigravity\scratch\pharmacy-system"
npm install
npm run dev -- --host --port 5180
```

لإعادة بناء المشروع للإنتاج:
```bash
npm run build
```
